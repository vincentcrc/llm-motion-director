# LLM专用生视频规则

一份 Claude Code 技能：让 LLM 用纯代码（设计、动画、配乐、质检）做视频时遵循的规则。内容包括 brief 字段、四种模式（showreel / product / launch-story / explainer）、素材/工艺/声音/构建底线、◆ 确认点工作流、带返工规则的独立评审循环、质量标准和交付清单。

## 安装

```bash
mkdir -p ~/.claude/skills/LLM专用生视频规则
cp LLM专用生视频规则skill.md ~/.claude/skills/LLM专用生视频规则/SKILL.md
```

Claude Code 只认技能目录里的 `SKILL.md`，所以安装时要改回这个文件名。
